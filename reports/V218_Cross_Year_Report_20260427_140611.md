## 2. V218 Core Architecture (V218 核心架构)

### 2.1 Market State Adapter (市场状态适配器)
- **State Detection**: 使用大盘 std(ret_20) 和 ma(close, 20) 判定市场状态
- **Regime Classification**:
  - 极值恐慌 (CRISIS): 高波动 + 下跌趋势 -> 适合反转策略
  - 趋势爆发 (TREND): 低波动 + 上涨趋势 -> 适合动量策略
  - 正常区间 (NORMAL): 介于两者之间

### 2.2 Feature Decoupling (特征解耦)
- **Score_Rev (反转得分)**: 短期反转逻辑 (5d/10d/20d)
- **Score_Mom (动量得分)**: 20日价格强度 + 中期动量
- **Gating Mechanism**: Final_Score = W_t * Score_Rev + (1 - W_t) * Score_Mom

### 2.3 Dynamic Weight Calculation (动态权重)
- W_t = sigmoid(alpha * volatility_norm + beta * trend_strength)
- 其中 alpha=1.5, beta=1.0 为默认参数
