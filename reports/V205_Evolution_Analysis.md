### 2.2 高阶矩特征 (Higher Moments)

#### 偏度 (Skewness)
```
Skewness = E[(X - μ)³] / σ³
```
- **正偏度**: 右尾更长，存在极端大值
- **负偏度**: 左尾更长，存在极端小值（风险更大）
- **应用**: 偏好正偏度股票，规避左尾风险

#### 峰度 (Kurtosis)
```
Kurtosis = E[(X - μ)⁴] / σ⁴
```
- **高峰度**: 厚尾，极端事件更多（风险更高）
- **低峰度**: 薄尾，极端事件更少
- **应用**: 偏好低峰度股票，规避极端波动

#### 实现方案
```python
# 20 日滚动偏度和峰度
skewness_20 = rolling_skewness(return_1d, 20)
kurtosis_20 = rolling_kurtosis(return_1d, 20)

# 60 日滚动偏度和峰度
skewness_60 = rolling_skewness(return_1d, 60)
kurtosis_60 = rolling_kurtosis(return_1d, 60)

# 对波动率正交化（剥离波动率影响）
skewness_20_ortho = orthogonalize(skewness_20, volatility_20)
kurtosis_20_ortho = orthogonalize(kurtosis_20, volatility_20)
```
