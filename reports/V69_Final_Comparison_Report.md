## 📊 V69 核心算法 - 资金流驱动预测

### 1. 预测逻辑

```
┌─────────────────────────────────────────────────────────────┐
│                    V69 预测引擎架构                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【输入层】                                                  │
│  ├── 股票日线数据 (stock_daily)                             │
│  ├── 资金流数据 (stock_fund_flow) ← 核心驱动                │
│  └── 行业数据 (stock_industry_daily)                        │
│                                                             │
│  【特征层】                                                  │
│  ├── 资金共振：主力净流入占比变动趋势                       │
│  ├── 机构踪迹：主力净额/流通市值                            │
│  ├── 行业护城河：RS-ZScore + 行业百分位                     │
│  ├── VCP 动态阈值：振幅收缩验证                             │
│  └── 价格回调：MA20 支撑验证                                │
│                                                             │
│  【预测层】                                                  │
│  ├── 5 日远期收益率 (Forward 5D Return)                     │
│  ├── 预测排名 (Predicted Rank)                              │
│  └── 综合评分 (Composite Score)                             │
│                                                             │
│  【审计层】                                                  │
│  ├── Rank IC：预测排名与实际收益排名的相关性                │
│  └── CSI：换手敏感度 (收益率/交易次数)                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2. 审计指标要求

| 指标 | 目标值 | 最低容忍值 | 说明 |
|------|--------|------------|------|
| **Rank IC** | > 0.02 | > 0.01 | 预测排名与实际收益排名的相关性 |
| **月度 Rank IC 均值** | > 0.02 | - | 月度稳定性要求 |
| **CSI** | > 0.05 | > 0.02 | 换手敏感度 (收益率/交易次数) |
