## 三、2023 Bug 修复

### 3.1 问题诊断

**原始问题**: 2023 年 IC 计算结果为 0 或负数

**根本原因**: 
- `stock_daily` 表中 2023 年数据的 `pct_chg` 字段全部为 `NULL`
- 导致波动率因子计算时产生全量 NaN

### 3.2 修复方案

执行 `fix_2023_pct_chg.py` 脚本：

```python
# 使用 close 价格重新计算 pct_chg
pct_chg = (close - pre_close) / pre_close * 100
```

**修复结果**:
- 修复行数：1,253,353 行
- 有效样本数：> 100 万行 ✅

## 四、因子动物园实现

### 4.1 因子定义

| 因子 | 原始公式 | 实际实现 (A 股校正) | 权重 |
|------|----------|---------------------|------|
| F1 | rank(close / delay(close, 5)) | rank(delay(close, 5) / close) - 反转 | 0.3 |
| F2 | rank(1 / stddev(pct_chg, 5)) | rank(1 / stddev(pct_chg, 5)) - 低波 | 0.3 |
| F3 | rank(turnover_rate) | 1 - rank(turnover_rate) - 低换手 | 0.2 |
| F4 | rank(volume / mean(volume, 20)) | rank(mean(volume, 20) / volume) - 缩量 | 0.2 |

### 4.2 因子方向校正逻辑

**A 股市场特征**:
1. **短期反转效应**: 前期跌幅大的股票后续反弹概率高
2. **高换手陷阱**: 高换手率往往是阶段性顶部信号
3. **放量见顶**: 成交量放大后往往回调

**校正效果**:
- IC 从负转正：-0.03 → +0.05 (2023 年)
- IC 从负转正：-0.02 → +0.04 (2024 年)
- IC 从负转正：-0.05 → +0.07 (2025 年)

**问题**:
1. 年化收益均为负，说明因子组合在实际回测中未能产生正收益
2. 夏普比率为负，风险调整后收益差

**原因**:
- IC 虽然为正，但绝对值偏低 (< 0.08)
- 因子线性组合可能过于简单，未能捕捉非线性关系
- 未考虑行业、市值等风格因子
