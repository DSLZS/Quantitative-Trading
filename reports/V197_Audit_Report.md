【数学论证】

在 EXTREME 状态下：
- 波动率急剧上升：volatility_regime = ATR / ATR_ma20 > 80th percentile
- 收益率分布呈现高峰度：kurtosis ≈ 19.1 (2024 EXTREME 状态)
- 因子共线性增强，信号质量下降

3. 因子失效的数学原因：

【reversion_5 失效 (-41%)】
- 在 EXTREME 状态下，市场呈现"强者恒强"特征
- 反转策略假设均值回归，但极端市场中趋势持续
- 数学表达：E[return | extreme] ≠ 0, 而是 E[return | extreme] ∝ momentum

【volume_rank 失效 (-48%)】
- 极端市场中，成交量放大往往伴随价格波动加剧
- 高成交量股票不再代表低预期收益
- 成交量与收益的相关性在 EXTREME 状态下显著下降

【liquidity_alpha 失效 (-71%)】
- OFI (Order Flow Imbalance) 假设在正常市场中有效
- 极端市场下，流动性溢价机制失效
- IC 从 0.0245 降至 0.0070，几乎完全失去预测能力

1. MarketContext 市场状态识别类 (NEW)

【数学实现】
volatility_regime = ATR / ATR_ma20
return_skew = skew(returns_20d)  # 偏度
return_kurt = kurtosis(returns_20d)  # 峰度
volume_anomaly = volume / volume_ma20

状态分类逻辑：
- EXTREME: volatility_regime > 80th percentile
- TREND: return_skew > median
- RANGE: 其他

【代码实现】
```python
class MarketContext:
    def classify_regime(self, df: pd.DataFrame) -> pd.Series:
        daily_stats = df.groupby('trade_date').agg({...})
        vol_threshold = daily_stats['volatility_regime'].quantile(0.8)
        skew_threshold = daily_stats['return_skew'].quantile(0.5)
        
        def _classify(row):
            if row['volatility_regime'] > vol_threshold:
                return 'EXTREME'
            elif row['return_skew'] > skew_threshold:
                return 'TREND'
            else:
                return 'RANGE'
```

六、2024 年 IC 未达标的根本原因分析
================================================================================

尽管 V197 引入了市场状态识别机制，但 2024 年 IC 仍为 0.0498，原因如下：

1. **状态分类基于截面统计量**
   - 当前实现使用截面分位数分类，导致所有年份的 EXTREME 状态定义不同
   - 需要改用绝对阈值或跨年度统一分位数

2. **因子池限制**
   - 在 EXTREME 状态下，即使抑制失效因子，剩余有效因子 (volatility) 的 IC 仍然有限
   - volatility_5 IC=0.047, volatility_20 IC=0.041，无法支撑整体 IC>0.08

3. **权重融合滞后**
   - 当前使用"当前状态"进行权重调整，但因子 IC 计算使用全样本
   - 需要实现"状态条件 IC"计算

4. **非线性惩罚未完全生效**
   - 当前实现在 compute_score 中应用权重，但非线性惩罚未完全整合
