## 2. V89 核心重构

### 2.1 半衰期衰减权重（Half-Life Decay Weighting）

```python
# V89 固定权重配置
V89_LAG1_WEIGHT = 0.50  # Lag 1 权重 50%（必须 > 30%）
V89_LAG3_WEIGHT = 0.30  # Lag 3 权重 30%
V89_LAG5_WEIGHT = 0.20  # Lag 5 权重 20%
```

**设计原理**：
- 近期信号（Lag 1）应获得更高权重，因为预测能力更强
- 半衰期衰减符合信息衰减的自然规律
- 固定权重避免过拟合，提高样本外稳定性

### 2.2 Vol_Price_Interaction 因子优化

**V89 新增特性**：
1. **量价背离二阶导数**：检测量价关系的加速度变化
2. **传统 interaction 保留**：0.7 × 传统 interaction + 0.3 × 背离增强
3. **10 日动量捕捉**：使用 10 日而非 5 日动量，捕捉中期趋势
4. **成交量确认**：量价配合验证信号可靠性

```python
# 最终分数计算
vol_price_interaction_score = 0.7 * interaction_score + 0.3 * volume_price_divergence_score
```

### 2.3 换手率控制机制

**V89 换手率管理**：
1. **调仓间隔**：42 天（季度调仓）
2. **缓冲阈值**：60%（权重变化超过 60% 才调仓）
3. **单日换手率分摊**：调仓日换手率分摊到 42 天，更符合实际交易
