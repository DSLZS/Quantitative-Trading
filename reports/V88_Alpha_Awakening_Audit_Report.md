```python
# Score < 60 强制权重归零
```

### 2. 时空波动率融合 (V88AlphaFusion)

```python
# IC 动态权重计算 (IC 倒数)
ic_weights = {lag: 1.0 / abs(ic[lag]) for lag in [1, 3, 5]}
# 归一化
total = sum(ic_weights.values())
ic_weights = {k: v/total for k, v in ic_weights.items()}
```
